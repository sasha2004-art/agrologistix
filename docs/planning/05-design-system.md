# Design System & UI Specification — «Serenity» (calm / neumorphic)

> Стиль основан на запросе: *calming mental health landing page with neumorphic elements,
> mood tracking preview, therapy session booking, resource library, crisis support — soothing pastels.*

## 1. Общие принципы

* **Фреймворк:** чистый **Vuetify 4** (тема `serenityLight`) + scoped SCSS. **Tailwind не используется.**
* **Стиль:** **Neumorphism (Soft UI)** на пастельной лавандовой базе. Элементы «выдавлены» из фона мягкой
  двойной тенью (тёмная + светлая), радиус 16–24px, один источник света сверху-слева.
* **Атмосфера:** спокойствие, тишина, бережность. Никакого неона, резких контрастов, «стекла» и градиентных свечений.
* **Режим:** светлая тема — основная. Тёмная — опционально (см. §7), для неё неоморфизм требует отдельного
  набора теней, поэтому она не включена по умолчанию.

### Обязательное ограничение доступности

Скилл `ui-ux-pro-max` помечает neumorphism как **accessibility risk: high**: мягкие тени не дают
достаточного контраста границ и состояний. Поэтому в этой теме действует правило:

> **Тень никогда не является единственным носителем смысла или состояния.**
> Любой интерактивный элемент дополнительно имеет текстовую метку, иконку, цвет или границу,
> а состояния (`hover` / `focus` / `pressed` / `disabled`) различимы без учёта тени.

Компенсации заложены в токены и проверены численно (см. §2.3).

## 3. Типографика и сетка

* **Заголовки:** `Lora` (serif) — мягкие, «человечные», fallback `'PT Serif', Georgia, serif`.
* **Текст:** `Raleway` (sans) — fallback `'Segoe UI', system-ui, -apple-system, sans-serif`.
* **Цифры и метрики:** `'JetBrains Mono', ui-monospace, monospace`.
* Шрифты **не подключаются с внешних CDN** (офлайн-требование проекта). Вариант self-host:
  `@fontsource/lora` + `@fontsource/raleway` (добавляется отдельной задачей). До этого используется
  системный fallback, метрики текста от него не зависят.
* Базовая шкала: 12 / 14 / 16 / 18 / 24 / 32 / 44 / 56 px. Межстрочный 1.6 для текста, 1.15 для заголовков.
* Контейнер лендинга: `max-width: 1120px`; секции — вертикальный ритм 64–96px (мобильный 40–56px).

### Структура лендинга (`/`)

Лендинг сознательно сведён к минимуму — это точка входа, а не витрина:

1. **App bar** (`.soft-bar`): только бренд `Serenity`. Без навигации и без CTA.
2. **Центрированная кнопка «Войти»** (`accent`, `size="large"`, `min-width: 200px`) — единственный
   интерактивный элемент страницы, ведёт на `/login`.

Секции hero, mood preview, booking, library, crisis support, testimonials и footer удалены.

## 4. Спецификация экранов

### Экран 1: Лендинг (`/`) — минимальная точка входа

* Фон `#F2ECFB` без градиентов и декоративных элементов.
* App bar `.soft-bar` содержит только бренд (иконка + название), без навигации.
* Единственный интерактивный элемент — кнопка **«Войти»**: `size="large"`, `min-width: 200px`,
  цвет `accent`, класс `.btn-gradient`, переход на `/login` обычным `RouterLink`-переходом.
* Кнопка центрируется по вертикали и горизонтали; на узких экранах — с отступами 24px.
* Никаких секций, карточек, форм и внешних ссылок на странице нет.

### Экран 2: PIN-терминал (`/login`) — перекрашен в новую тему

* Центрированная `.soft-card`, `max-width: 420px`, неоморфная поверхность.
* 6 точек-индикаторов 16px: пустая — `.neu-inset` + страховочная граница `rgba(91,81,117,.28)`;
  заполненная — `primary` заливка; ошибка — `error` заливка + `keyframes shake` 300ms
  (отключается при `prefers-reduced-motion`).
* Ошибка объявляется через `role="alert"` (`v-alert type="error"`), не только цветом.
* Ввод PIN не отменяет вставку из буфера и поддерживает `autocomplete="one-time-code"`.

### Экран 3: Дашборд (`/dashboard`) — перекрашен в новую тему

* App bar `.soft-bar`, контейнеры `.soft-card`, чипы `.soft-chip`, алерты — тональные.
* Плотность: сетка 8px, ритм секций 16/24/32/48.
* Обязательные состояния: `loading` (`v-skeleton-loader` / `v-progress-linear`),
  `empty` (подсказка), `error` (`v-alert`, `role="alert"`), `filled`.
* Таблицы: зебра на `surface-variant`, липкая шапка, выделение строки без опоры только на цвет.

### Экран 4: Печать (`@media print`)

* Скрываются app bar, навигация и декоративные тени (`box-shadow: none`), фон — белый.
* Чёрно-белый документ A4: шапка, номер, таблица точек/сессий, блок подписей.

## 5. Интеракции и motion

* Hover: подъём `.soft-card` на 1–2px + смена границы, 150–200ms `ease-out`.
* Press: `.neu-press` (вдавливание), 120ms. Сдвиг не выходит за границы элемента → нет jitter.
* Focus: `:focus-visible` → кольцо `2px #6D28D9` + `outline-offset: 3px` (не тень!).
* Никакой автопрокрутки и бесконечных анимаций. Карусель отзывов заменена на статичную сетку.
* `prefers-reduced-motion: reduce` → все transition/animation выключаются.

## 6. Anti-patterns (запрещено)

* Тень как единственный индикатор состояния, кликабельности или ошибки.
* Неоновые и «кислотные» цвета, агрессивные градиенты, glassmorphism, `backdrop-filter`.
* Emoji в качестве структурных иконок — только вектор (MDI/Phosphor).
* Автокарусели, авто-видео, бесконечные loop-анимации.
* Мелкий текст < 12px и касательные цели < 44×44px.
* Скрытие кризисного блока за скроллом или под «показать ещё».

## 7. Тёмная тема (опционально, не включена)

При включении обязателен отдельный набор теней (неоморфизм на тёмном фоне инвертирует световую модель)
и независимая проверка контрастов. До этого момента переключатель темы в UI отсутствует.

## 8. Чек-лист перед сдачей

- [ ] Ни один интерактивный элемент не обозначен только тенью
- [ ] Текст ≥ 4.5:1, крупный ≥ 3:1, границы/иконки ≥ 3:1 (проверено численно)
- [ ] Видимый `:focus-visible` на всех интерактивных элементах
- [ ] Все иконки — вектор, без emoji
- [ ] Mood/статусы дублированы текстом, а не только цветом
- [ ] `prefers-reduced-motion` уважается
- [ ] Проверено на 375 / 768 / 1024 / 1440px
- [ ] Касательные цели ≥ 44×44px

# Design System & UI Specification (Vuetify 4)

## 1. Общие принципы и Стилизация
* **Фреймворк:** Чистый **Vuetify 4** (материальные компоненты, встроенные пропсы отступов и цветов, Scoped SCSS для микро-анимаций). **Tailwind CSS не используется.**
* **Стиль:** минималистичный Material Design. Только плоские поверхности и стандартная шкала elevation. Запрещены видеофоны, glassmorphism и `backdrop-filter`, градиенты, свечения и шрифты с внешних CDN.
* **Тема по умолчанию:** `agroLight` — светлая спокойная тема с фермерскими ассоциациями: белая основа, пшенично-жёлтый как главный акцент, небесно-голубой как второй акцент, зелёный — минимально и только как индикатор выполненного статуса.

### Цветовая палитра (Vuetify Theme Config)

| Токен | HEX | Назначение |

| `background` | `#FFFFFF` | Основной белый фон рабочей области |

| `on-surface-variant` | `#5B584F` | Вторичный текст, подписи, единицы измерения |

| `secondary` | `#8CBEDC` | Небесно-голубой второй акцент: метеоданные, рефрижератор `has_reefer` |

## 2. Типографика и Сетка
* **Шрифт:** `Roboto`, `Helvetica Neue`, sans-serif; моноширинный `JetBrains Mono` для цифр TCO, тоннажа, координат и таймингов.
* **Макет рабочего места (`/dashboard`):** Фиксированный `100vh` без вертикального скролла всей страницы (`overflow: hidden`):
  * **Top App Bar (`56px` высота):** Логотип, индикатор региона (*Калужская обл. / Обнинск*), виджет текущей погоды с переключателем стресс-режима, кнопка `Сравнение Было/Стало`, кнопка `Hard Reset Demo` (видна только при `is_admin = true`), кнопка выхода.
  * **Левая панель управления (`35%` ширины, `min-width: 440px`):** Вкладки Vuetify (`v-tabs`): `1. Склады и Заявки`, `2. Автопарк`, `3. Маршруты и TCO`. В нижней части закреплён (`sticky`) блок действия с главной кнопкой **«Рассчитать поставки»** (`v-btn color="primary" size="large" block`).
  * **Правая область карты (`65%` ширины):** Полноэкранный холст Mapbox GL JS со светлым стилем `mapbox://styles/mapbox/light-v11`, плавающими легендами маршрутов и быстрыми карточками событий.

## 3. Спецификация ключевых экранов и состояний

### Экран 1: Публичный Лендинг (`/`)
* Лаконичный первый экран: заголовок, короткое описание B2B-системы био-логистики Калужской области и кнопка **«Открыть терминал логиста»** (ведёт на `/login`).
* Три плоские карточки `v-card variant="outlined"` с ключевыми возможностями (свежесть груза, маршруты и автопарк, экономика рейса). Без декоративных блоков, схем маршрутов и «стеклянных» панелей.

### Экран 2: Минималистичный терминал ввода PIN-кода (`/login`)
* Центрированная карточка (`v-card variant="outlined"`, максимум `420px`).
* **Сверху:** Название системы `AGROLOGISTIX` и подзаголовок `Введите 6-значный PIN-код диспетчера`.
* **Индикация ввода:** Горизонтальный ряд из **6 точек-индикаторов** (`14px x 14px`, `border-radius: 50%`). Сами вводимые цифры **никогда не отображаются**.
  * *Пустая точка:* `border: 2px solid rgba(43, 42, 38, 0.24)`, прозрачный фон.
  * *Заполненная точка:* `primary` (`#D9B36C`) в границе и фоне, плавная смена цвета за `150ms`.
  * *Авто-проверка:* При нажатии 6-й цифры сразу отправляется запрос без кнопки «Войти».
  * *Состояние ошибки (`error`):* Все 6 точек окрашиваются в `error` (`#B4553F`), ряд точек проигрывает анимацию `keyframes shake` (амплитуда `6px`, длительность `300ms`), после чего массив ввода автоматически сбрасывается до 0 заполненных точек.
  * *Ошибка текстом:* неблокирующий `v-alert type="error" variant="tonal"` с сообщением о непринятом PIN-коде.

### Экран 3: Главный дашборд и Сравнение «Было / Стало» (`/dashboard`)
* **Состояния каждого блока:**
  * `loading`: Скелетоны `v-skeleton-loader` в таблицах ERP и линейный индикатор `v-progress-linear` поверх карты при работе солвера.
  * `empty`: Подсказка «Нажмите „Рассчитать поставки" для построения оптимального плана».
  * `error`: Неблокирующий `v-alert` с описанием причины (например, при нехватке фур подсвечивается объём `Unmet Demand`).
  * `filled`: Отрисованные полилинии рейсов на карте (каждая машина — свой цвет), маркеры складов (иконка ангара) и клиентов (бейдж `Асфальт` / `Грунтовка` + чекбокс `Доставлено`), сводные карточки TCO и модальная/встроенная панель **«Было / Стало»** с дельтами в рублях и процентах (`+` / `-`).

### Экран 4: Печатный Маршрутный лист (`@media print`)
* При вызове печати скрываются карта, сайдбар и шапка (`display: none !important`).
* Рендерится строгий чёрно-белый документ формата А4: шапка агрохолдинга, номер рейса, госномер машины, статус рефрижератора, погодный режим, таблица точек по порядку объезда (клиент, тип дороги, культура, вес в кг, плановое время прибытия, ожидаемая свежесть %) и блок подписей «Сдал склад / Принял водитель / Принял клиент».
